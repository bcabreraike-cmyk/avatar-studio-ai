## 📋 Quick Start (5 minutes)

### Step 1: Clone & Install
```bash
git clone https://github.com/bcabreraike-cmyk/avatar-studio-ai
cd avatar-studio-ai
pnpm install
```

### Step 2: Detect GPU
```bash
pnpm run setup:gpu
```

**Expected output for M3/M4 Pro:**
```
🔍 Detecting GPU and system capabilities...
Platform: darwin
Architecture: arm64
CPU Count: 12
Total Memory: 18.00 GB

📱 Detected macOS
Metal GPU Support: ✅ YES
✨ Apple Silicon detected: Apple M3 Pro

✅ GPU Detection Complete!
📋 Recommended Configuration:
   GPU Type: METAL
   Workers: 6
   Max Memory: 12 GB
   Batch Size: 2
```

### Step 3: Configure Environment
```bash
cp .env.example .env
# Edit .env if needed, otherwise defaults are fine for M-series
```

### Step 4: Download Models (Optional for testing)
```bash
# For quick testing, skip this
# To download: pnpm run setup:models -- --minimal
```

### Step 5: Start Backend
```bash
pnpm run dev:backend
```

**Expected output:**
```
✅ AvatarStudio AI Backend running at http://localhost:3000
📚 API Documentation: http://localhost:3000/api/docs
🔍 Health Check: http://localhost:3000/health
```

## 🐛 Troubleshooting Tests

### Backend won't start
```bash
# Check ports
lsof -i :3000

# Kill if needed
kill -9 <PID>

# Try different port
BACKEND_PORT=3001 pnpm run dev:backend
```

### API not responding
```bash
# Check backend is running
curl http://localhost:3000/health

# Check logs
pnpm run dev:backend --verbose
```

### Metal GPU not detected
```bash
# Re-run detection
pnpm run setup:gpu

# Force Metal mode
GPU_TYPE=metal pnpm run dev:backend
```
